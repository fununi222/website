**VAST Data** は分析において優れたですが、オーケストレーションの自作が必要です。対照的に **Rubrik** はポリシーによる「完全自動の持ち出し」を優先する組織に最適です。

2. 調査の背景と目的

クラウドネイティブな運用において、スナップショットは非常に強力なツールだが、それは「AWSアカウント内」に閉じた保護であることが多い。真の復元力と、オンプレミスの強力な分析基盤（VAST Data 等）を活かした AIOps を実現するためには、AWS DataSync や Parquet フォーマットを活用した効率的なデータ移動が必要となる。

3. アーキテクチャ上の留意点

  • Egressコスト: AWSからのデータ転送費用は、設計段階で最も慎重に評価すべき項目である。
  • APIレート制限: 大規模なスナップショットエクスポートは AWS API の制限に抵触しやすいため、Event Orchestration による制御が推奨される。
