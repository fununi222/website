# Design System Reference

Use this reference when a task changes layout, component styling, article presentation, or global UI direction.

## Technical Archive

- Preserve the research-lab atmosphere: dark, high-contrast, polished, and slightly futuristic.
- Keep the existing shared styling centered on `assets/css/synthetic.css`.
- Keep the existing Tailwind runtime configuration centered on `assets/js/tw-config.js`.
- Treat legacy `style.css` usage as archival unless the task explicitly requires revival.

## Visual Rules

- Primary accent: `#aaa4ff`
- Secondary accent: `#00d2ff`
- Background base: `#060e20`
- Success/status-safe: `#10b981`
- Warning/manual-attention: `#f59e0b`
- Critical/high-risk: `#e11d48`

## Typography

- Headlines: `Space Grotesk` with `Noto Sans JP` for Japanese copy.
- Body: `Inter` with `Noto Sans JP` for Japanese copy.
