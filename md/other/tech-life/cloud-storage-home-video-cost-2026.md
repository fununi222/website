# ホームビデオ向けクラウドストレージ最安比較｜容量別・家族共有コスパをファクトチェック

スマートフォンの4K動画、子どもの成長記録、旅行動画は、写真よりもはるかに速くストレージを消費します。無料枠だけで運用すると、Googleアカウントの15GB、iCloudの5GB、OneDriveの5GBはすぐに上限へ到達します。

本記事では、2026年8月17日時点で確認できる公式料金・公式説明をもとに、Google One / Google AIプラン、iCloud+、Microsoft 365、Dropbox、pCloud、家族アルバム みてねをファクトチェックし、**「容量単価」ではなく、家族運用で本当に破綻しにくい保存設計**として整理します。

> 重要：クラウド料金は地域・キャンペーン・アプリ内課金経路で変動します。最終契約前には必ず公式ページの表示価格を確認してください。

---

## 1. ファクトチェック結論：修正すべきポイント

先に結論です。元レポートの大枠、つまり「みてねは家族動画共有に強い」「Microsoft 365 Familyは人数が多いほど強い」「Google One 2TBは家族共有プールとして有力」「pCloudは長期利用でサブスク回避になる」という方向性は妥当です。

ただし、公開記事にするなら以下は修正しておくべきです。

| 論点 | 判定 | 修正内容 |
| :--- | :--- | :--- |
| Microsoft 365 Familyの月額換算 | **要修正** | 年額27,400円なら月額換算は約2,283円です。本文の「月額換算2,740円」は計算ミスです。 |
| Google AI Proのモデル名 | **要修正** | 公式表記は「Pro model」「Deep Research」等であり、「Gemini 3.1 Pro」と断定する根拠は確認できませんでした。 |
| iCloud+日本価格 | **確認済み** | Apple公式サポート上の日本価格は50GB 180円、200GB 540円、2TB 1,800円、6TB 5,500円、12TB 11,000円/月です。 |
| Microsoft 365 Basic / Family | **確認済み** | Microsoft公式の日本向けOneDrive料金ページで、Basicは年額2,440円、Familyは年額27,400円と確認できます。 |
| pCloud Family | **確認済み・注意** | Family 2TB / 10TBは買い切り型。ただし表示通貨やセール価格が変わるため、記事では「通常価格・セール変動あり」と明記すべきです。 |
| みてね | **確認済み・注意** | 無料でも動画投稿は可能ですが、無料プランは1本あたりの長さ制限があり、プレミアムでは長尺動画やPCアップロード等が強化されます。 |

## 2. 目的別の最適解

### 子どもの日常動画を祖父母まで簡単に共有したい

最初に検討すべきは、汎用クラウドではなく**家族アルバム みてね**です。無料で写真・動画の家族共有を始められ、プレミアムでは長い動画、PCアップロード、高画質関連の機能が強化されます。

ただし、みてねは「家族向け閲覧・共有体験」に最適化されたサービスです。RAW動画、編集前素材、巨大な4Kファイルを原本アーカイブする用途では、Google One、iCloud+、OneDrive、pCloudなどと併用するのが安全です。

### 家族それぞれが独立した1TBを安く持ちたい

**Microsoft 365 Family**が最有力です。日本向け公式価格は年額27,400円で、1〜6人用です。6人で使う場合、1人あたり年額約4,567円、月額約381円で1TBのOneDrive領域を持てます。

最大の強みは、容量が「1TB × 最大6人」と個別に分かれる点です。家族間で容量を奪い合わず、プライバシーも分離しやすい一方、1人が6TBをまとめて使うことはできません。

### 家族で2TB〜5TBを柔軟に分けたい

Android、Googleフォト、Gmail、Google Drive中心なら、**Google One 2TB**または**Google AI Pro 5TB**が候補です。Google Oneはストレージを最大5人の追加メンバー、つまり自分を含めて最大6人相当で共有できます。

元レポートの「Google AI Proは5TB帯として強い」という評価はおおむね妥当です。ただし、AI機能名は頻繁に変わるため、「Gemini 3.1 Pro」といった未確認のモデル名で固定せず、公式表記に寄せて「GeminiアプリのProモデル、Deep Research、Google Workspace連携など」と書く方が安全です。

### Apple製品中心で写真アプリに統合したい

iPhone、iPad、Macの写真ライブラリ、端末バックアップ、iCloud写真を最優先するなら**iCloud+**です。日本価格は、50GBが180円/月、200GBが540円/月、2TBが1,800円/月、6TBが5,500円/月、12TBが11,000円/月です。

単純な容量単価ではGoogle OneやMicrosoft 365 Familyに負ける場面がありますが、Apple写真アプリとの統合、端末復元、ファミリー共有のわかりやすさは強力です。Apple中心の家庭では「最安」ではなく「運用ミスが少ない」ことに価値があります。

### サブスクを避けて長期アーカイブしたい

**pCloud Family Lifetime**は、2TBまたは10TBを家族で分配できる買い切り型プランです。短期では高額ですが、3〜5年以上使う前提なら、月額課金型より総コストを抑えられる可能性があります。

注意点は、買い切り型でもクラウド事業者リスクがゼロになるわけではないことです。ホームビデオの原本は、pCloud単独ではなく、外付けSSD / NAS / 別クラウドとの二重化を推奨します。

| 容量帯 | 有力候補 | 公式確認ベースの評価 |
| :--- | :--- | :--- |
| 50GB | iCloud+ 50GB | Apple端末バックアップの最小課金として安い。動画保存にはすぐ不足します。 |
| 100GB | Microsoft 365 Basic / Google One Basic | OneDrive 100GBは年額2,440円。Googleフォト中心ならGoogle Oneも候補。 |

## 4. ホームビデオ保存の推奨アーキテクチャ

クラウド選びで最も危険なのは、「安い1サービス」に全動画を集中させることです。家族の動画は再撮影できないため、料金比較だけでなく、復旧性を設計すべきです。

おすすめは次の三層構造です。

1. **共有レイヤー**：みてね、Googleフォト、iCloud写真など、家族が日常的に見る場所。
2. **原本レイヤー**：OneDrive、Google Drive、pCloud、外付けSSDなど、編集前の動画を保存する場所。
3. **バックアップレイヤー**：別クラウドまたはオフライン媒体。誤削除、アカウント停止、同期ミスに備える場所。

この設計にすると、「祖父母に見せる動画」と「将来編集する原本」を分けられます。結果として、家族共有アプリの使いやすさと、長期保存の安全性を両立できます。
