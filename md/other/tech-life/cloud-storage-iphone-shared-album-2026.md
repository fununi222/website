# iPhone共有アルバムで動画容量を節約する方法｜クラウドストレージ比較つき

iPhoneやスマートフォンで撮る動画は、写真よりもずっと早く容量を使います。子どもの日常動画、旅行、発表会、運動会を残していると、無料のiCloud 5GBやGoogleアカウントの無料枠だけでは足りません。

ただ、いきなり高いクラウドプランへ移る前に、用途を分けて考えると無駄な課金を減らせます。

この記事では、2026年8月17日時点で確認できる公式情報をもとに、次の2つを整理します。

- ホームビデオ向けクラウドストレージの現実的な選び方
- iPhoneの「共有アルバム」を使った無料保存の使いどころと限界

結論から言うと、**共有アルバムは“無料の閲覧用保管場所”としては便利ですが、4K動画や大切な原本のバックアップ先には向きません**。日常動画は共有アルバムやみてね、原本はiCloud+、Google One、Microsoft 365、pCloud、外付けSSDに分けるのが安全です。

> 料金、容量、付帯機能は地域・契約経路・キャンペーンで変わります。契約前には必ず公式ページの表示を確認してください。

## 3. iPhone共有アルバムは無料ストレージとして使えるのか

### 3-1. iCloud容量にはカウントされない

Appleの共有アルバムは、通常のiCloud写真とは別の仕組みです。Apple公式サポートでは、共有アルバム内の写真と動画はiCloudに保持されるものの、iCloudストレージ容量にはカウントされないと説明されています。

そのため、iCloud無料枠の5GBがほぼ埋まっている人でも、共有アルバムを使えば写真・動画を追加できる場合があります。

ただし、これは「オリジナル画質の無料バックアップ」ではありません。共有アルバムに追加されたデータは、共有しやすいサイズへ縮小・変換されます。

### 3-2. 自分専用アルバムとしても使える

共有アルバムは、家族や友人へ見せるための機能です。ただし、アルバム作成時に参加者を追加しなければ、自分だけで使う保管用アルバムとして運用できます。

おすすめの使い方は、次のように年別・用途別で分ける方法です。

- `日常メモ_2026`
- `子ども短尺動画_2026`
- `レシート・スクショ保管`
- `SNS用動画アーカイブ`

1アルバムに詰め込みすぎると探しにくくなるため、最初から分けておく方が後で楽です。

## 4. 共有アルバムの仕様と制限

共有アルバムは便利ですが、制限を理解せずに使うと後悔します。特に動画と画質の制限が重要です。

| 項目 | 仕様 | 実務上の意味 |
| :--- | :--- | :--- |
| iCloud容量 | カウントされない | 無料枠の節約に使えます。 |
| 写真サイズ | 長辺2048pxまで | スマホ閲覧には十分ですが、大判印刷やトリミングには弱いです。 |
| パノラマ写真 | 最大幅5400pxまで | 通常写真より大きく保持されます。 |
| 動画の長さ | 1本15分まで | 長い動画は分割が必要です。 |
| 動画の画質 | 最大720p | 4Kや1080pの原本画質は残りません。 |
| 1アルバムの上限 | 写真・動画合計5000件 | 年別・用途別に分ける必要があります。 |
| 作成できる共有アルバム数 | 最大200個 | 理論上は最大100万件まで整理できます。 |
| 投稿制限 | 1時間1000件、1日10000件 | 大量移行は数日に分ける方が安全です。 |
| 空間写真・空間ビデオ | 非対応 | Apple Vision Pro向け素材の保存先には向きません。 |

重要なのは、共有アルバムが**保管場所として使える一方で、原本保存ではない**ことです。撮影時の4K画質、細かなメタデータ、編集耐性を残したい動画は、共有アルバムだけに置かないでください。

## 5. iPhone共有アルバムで容量を空ける手順

共有アルバムを使う時は、削除の順番を間違えないことが大切です。アップロード確認前に元データを消すと、失敗時に戻せなくなります。

```text
1. 共有アルバムをオンにする
2. 自分専用の共有アルバムを作る
3. 写真・動画を共有アルバムへ追加する
4. Wi-Fi環境でアップロード完了を確認する
5. 共有アルバム上で表示・再生できることを確認する
6. 元データをライブラリから削除する
7. 「最近削除した項目」から完全削除して容量を空ける
```

### 手順1：共有アルバムをオンにする

iPhoneで、`設定` → `Apple Account` → `iCloud` → `写真` を開き、`共有アルバム` をオンにします。

`iCloud写真`を使っていない場合でも、共有アルバムだけをオンにできる場合があります。

### 手順2：自分専用の共有アルバムを作る

写真アプリで `アルバム` → `＋` → `新規共有アルバム` を選びます。アルバム名を入力し、宛先の入力画面では誰も追加せずに作成します。

これで、自分だけが使う共有アルバムとして運用できます。

### 手順3：写真・動画を追加する

写真アプリのライブラリから保存したい写真や動画を選び、共有メニューから `共有アルバムに追加` を選びます。保存先のアルバムを確認し、投稿します。

大量に追加する場合は、数百件ずつに分ける方が失敗に気づきやすくなります。

### 手順4：元データを削除する

共有アルバムを開き、対象の写真や動画が表示・再生できることを確認します。その後、通常のライブラリから元データを削除し、最後に `最近削除した項目` から完全削除します。

この最後の完全削除まで行うと、iPhone本体の空き容量が増えます。

## 6. 共有アルバムのメリット・デメリット

### メリット

- 無料で使える
- iCloudストレージ容量にカウントされない
- iPhoneの本体容量を空ける用途に使いやすい
- 家族や自分の別デバイスから見返しやすい
- 短い動画やメモ写真の退避に向いている

### デメリット

- 写真は長辺2048pxに縮小される
- 動画は最大720p、15分まで
- 自動バックアップではなく手動運用
- 共有アルバムを消すと中身も消える
- 再保存時にメタデータが元通り残らない場合がある
- 重要な動画の唯一の保存先にするには不安がある

つまり、共有アルバムは「無料で見返せる軽量コピー置き場」と考えるのがちょうどよいです。

## 8. おすすめのハイブリッド運用

動画保存は、1つのサービスだけに任せない方が安全です。次のように、役割で分けると失敗しにくくなります。

### 日常メモ・短い動画

- 保存先：iCloud共有アルバム
- 例：レシート、スクリーンショット、料理、短い日常動画
- 理由：多少画質が落ちても困りにくく、無料で本体容量を空けやすい

### 子どもの成長記録を家族に見せる動画

- 保存先：みてね
- 併用：重要な動画だけGoogle One、iCloud+、外付けSSDにも保存
- 理由：家族共有の使いやすさは汎用ストレージより高い

### 旅行・発表会・運動会・結婚式などの重要動画

- 保存先：iCloud+、Google One、Microsoft 365、pCloud、外付けSSD
- 共有用コピー：共有アルバムやみてね
- 理由：4Kや1080pの原本、撮影日時、編集耐性を残す必要がある

### 長期保存したい大量動画

- 保存先：pCloud Family、外付けSSD、NAS
- 予備：別クラウドにもう1コピー
- 理由：クラウド単独では、誤削除やアカウント問題に弱い

## 10. まとめ

iPhone共有アルバムは、iCloud容量を消費せずに写真・動画を置ける便利な機能です。無料で使えるため、iPhone本体の容量不足を一時的に解消したい人には役立ちます。

ただし、共有アルバムは原本保存ではありません。写真は縮小され、動画は720p・15分までに制限されます。大切な動画を共有アルバムだけに置くのは避けてください。

現実的には、次の使い分けがおすすめです。

- 日常の軽い写真・動画：共有アルバム
- 家族に見せたい子ども動画：みてね
- 重要な原本：iCloud+、Google One、Microsoft 365、pCloud、外付けSSD

無料機能をうまく使いつつ、残すべき原本にはきちんと保存先を用意する。これが、ホームビデオを長く安全に残すための一番シンプルな考え方です。
