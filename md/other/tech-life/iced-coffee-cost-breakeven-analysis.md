# コンビニ vs 社内アイスコーヒーの損益分岐点｜容量単価と実質コストを試算

オフィスワーク中に毎日飲むアイスコーヒーは、日々の習慣として定着しやすい一方で、毎月の固定費として着実に積み重なります。

「毎朝なんとなくコンビニで買っているけれど、出費がかさんでいる気がする」
「社内の温かいコーヒーに氷を足して自作すれば安くなると聞くが、氷代を含めても本当に差が出るのか？」

こうした疑問を整理するため、**セブンカフェ（アイス）**と**社内コーヒー（温）＋市販ロックアイス袋**の組み合わせについて、1杯あたりの実質コスト、容量（ml）単価、何杯で元が取れるかの損益分岐点、そして月間・年間のコスト差を試算しました。

---

## 概要（Summary）

- **実質コスト**: 社内コーヒー（70円）＋市販ロックアイス（約45円/杯）で、**1杯あたり約111〜118円（仕上がり400〜450ml）**。
- **損益分岐点**: ロックアイス袋（1.1kg / 289円）を購入した場合、セブンカフェLサイズ比較で**2杯目**、Rサイズ比較で**5杯目**に元が取れます。
- **容量単価**: 1mlあたり換算では、セブンカフェの約0.78〜0.83円/mlに対し、社内自作は約0.26〜0.28円/mlと**約3分の1**になります。
- **留意点**: 450ml以上のステンレスタンブラーが必要になる点や、氷の保管・持ち運びの手間といった運用のトレードオフが存在します。

---

## 1. 比較の前提条件と価格データ

比較対象とするセブンカフェと、社内コーヒーおよび市販ロックアイスの価格・容量データは以下の通りです。

### セブンカフェ（アイス）
| サイズ | 価格（税込） | 仕上がり総容量 | 推定氷量 |
| :--- | :--- | :--- | :--- |
| **アイスコーヒー R（レギュラー）** | 140円 | 約180ml | 約110〜120g |
| **アイスコーヒー L（ラージ）** | 250円 | 約300ml | 約170g |

### 社内コーヒー ＆ ロックアイス
| 項目 | 価格（税込） | 内容量 / 備考 |
| :--- | :--- | :--- |
| **社内コーヒー（温抽出）** | 70円 | 280cc |
| **セブンプレミアム ロックアイス（袋）** | 289円 | 1.1kg（約6〜7杯分） |
| **ロックアイス カップ** | 149円 | 400g（約2〜3杯分） |
| **ロックアイス グラス** | 145円 | 200g（1杯分） |

> **試算条件の選定**  
> 氷は単価が最も安く大容量の「ロックアイス袋（1.1kg / 289円）」を使用する前提とします。カップ氷やグラス氷は手軽ですが、1杯あたりの氷代が高くなるため除外しています。

---

## 2. 社内自作アイスコーヒーの実質コスト試算

社内の温かいコーヒー（280cc）にロックアイスを投入して急冷する場合のコスト内訳は以下の通りです。

```text
【1杯あたりの実質コスト内訳】
・社内コーヒー代（280cc） : 70円
・消費する氷（約160g）    : 約41〜48円（289円 ÷ 6〜7杯）
--------------------------------------------------
合計実質コスト            : 約111〜118円（仕上がり 400〜450ml）
```

温かいコーヒー280ccをしっかり冷やすには約160gの氷が必要となります。1.1kg入りの氷袋から約6〜7杯分が作れる計算になり、氷が溶けて加わることで仕上がり総量は約400〜450mlになります。

---

## 3. 損益分岐点（何杯で元が取れるか）

「大袋の氷を買っても、使い切る前に溶けたり飽きたりしたら損ではないか」という点について、損益分岐点を検証します。

### vs セブンカフェ Lサイズ（250円 / 約300ml）
- **1杯あたりの差額**: 社内自作の方が約135円安価（容量も社内の方が多い）
- **損益分岐点**: **2杯目**でクリア
  - セブンL 2杯: `250円 × 2 = 500円`
  - 社内自作 2杯（氷1袋購入）: `289円 + 70円 × 2 = 429円`
- **1袋（7杯分）使い切り時**: 779円 vs 1,750円（**約971円の差額**）

### vs セブンカフェ Rサイズ（140円 / 約180ml）
- **1杯あたりの差額**: 社内自作の方が約25円安価（容量は2倍以上）
- **損益分岐点**: **5杯目**でクリア
  - セブンR 5杯: `140円 × 5 = 700円`
  - 社内自作 5杯（氷1袋購入）: `289円 + 70円 × 5 = 639円`

週に2回以上アイスコーヒーを飲む環境であれば、氷袋を1袋購入して運用するだけで確実にコストメリットが生じます。

## 4. 容量単価（ml単価）の比較

価格だけでなく、「1mlあたりいくら支払っているか」を比較すると、ボリューム面での違いが明確になります。

| 選択肢 | 1杯の支払額 | 仕上がり容量 | 1mlあたりの単価 |
| :--- | :--- | :--- | :--- |
| **セブンカフェ R** | 140円 | 約180ml | **約0.78円/ml** |
| **セブンカフェ L** | 250円 | 約300ml | **約0.83円/ml** |
| **社内自作（280cc＋氷）** | 約115円 | 約400〜450ml | **約0.26〜0.28円/ml** |

社内自作の容量単価はセブンカフェの約3分の1です。デスクワークで長時間かけて多めの量を飲みたい場合、コスト効率は非常に高くなります。

## 5. 月間・年間コストシミュレーション（月20日勤務）

平日出勤（月20日）において、毎日アイスコーヒーを飲んだ場合の月間および年間の試算です。

```text
【1日1杯（Lサイズ相当・月20杯）飲む場合】
・セブンカフェ L : 5,000円 / 月（年間 60,000円）
・社内自作       : 約2,300円 / 月（年間 27,600円）※氷約3袋使用
--------------------------------------------------
差額（削減効果） : 月間 約2,700円 / 年間 約32,400円

【1日2杯（Lサイズ相当・月40杯）飲む場合】
・セブンカフェ L : 10,000円 / 月（年間 120,000円）
・社内自作       : 約4,600円 / 月（年間 55,200円）※氷約6袋使用
--------------------------------------------------
差額（削減効果） : 月間 約5,400円 / 年間 約64,800円
```

## 6. 実践における留意点と運用のコツ

社内自作には明確なコストメリットがある一方、日々の運用で考慮すべき点があります。

1. **タンブラーの容量選定**  
   温コーヒー280ccに氷160gを入れると400mlを超えるため、溢れないように500ml前後の真空断熱ステンレスタンブラーを用意することが推奨されます。結露防止と保冷力維持にも寄与します。

2. **冷凍庫での氷の固まり対策**  
   冷凍庫内で袋の氷が固まる場合があるため、使用前に袋の上から軽くほぐしておくと計量が容易になります。

3. **分割抽出の活用**  
   一度に400mlも必要ない場合は、温コーヒーを140ccずつ2回に分けて作ることで、1杯あたり約55〜60円でセブンRサイズ相当の適量を飲むことができます。
